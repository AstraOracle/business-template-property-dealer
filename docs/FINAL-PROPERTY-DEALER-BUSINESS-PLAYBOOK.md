# Property Dealer Website Business Playbook

This file is the non-technical playbook for selling, launching, handing over, and supporting this property dealer website business.

Use this when you want to:
- sell the website to dealers
- explain pricing
- close clients
- collect content
- launch the site
- hand it over
- manage support
- run this as a small business, not just a coding project

---

## 1. What You Are Selling

You are not selling:
- React
- Vite
- admin-lite system
- Google Apps Script
- Google Sheets backend

You are selling:
- a premium property dealer website
- direct WhatsApp enquiry system
- Google Sheets lead capture
- a simple admin page for content updates
- a no-tension, managed website setup

Best simple line:

> This is a premium property dealer website built to generate direct enquiries, send people to WhatsApp fast, and let the dealer update key content without technical headache.

---

## 2. Ideal Client Profile

Best fit clients:
- Gurgaon property dealers
- premium or mid-premium residential brokers
- people selling buy/rent/sell services
- dealers who want direct enquiries
- dealers who want better branding and trust
- dealers who heavily use WhatsApp
- small teams that want a simple website, not a full CRM

Bad fit clients:
- ultra-low-budget brokers
- random local brokers who only want “koi bhi site”
- clients who do not care about branding or trust
- clients who want everything for 2k to 5k
- clients who expect unlimited work for one-time payment

---

## 3. Core Offer

Recommended core offer:
- `₹25,000` one-time setup
- `₹1,000/month` support and maintenance

What this means:
- setup fee is for building, customizing, and launching the site
- monthly fee is for keeping the site managed, updated, and worry-free

Important:
You are not charging only for hosting cost.
You are charging for:
- responsibility
- support
- peace of mind
- technical handling
- small edits
- fixing issues if something breaks

Best explanation:

> You do not have to worry about hosting, technical issues, or keeping the site running. I handle that side for you.

---

## 4. What The Setup Fee Includes

The one-time fee should include:
- website setup
- business branding setup
- homepage setup
- buy page
- rent page
- sell page
- locality pages
- contact page
- lead form setup
- WhatsApp enquiry flow
- Google Sheets lead capture setup
- admin page setup
- logo/content/image insertion
- launch support

Keep scope limited and clear.

---

## 5. What Monthly Support Includes

Recommended monthly support includes:
- keeping the website live
- basic monitoring
- checking if forms and leads are working
- minor text edits
- small image replacements
- small content updates
- bug fixes
- helping the client if they get confused using admin

Do not include these by default:
- full redesign
- major new features
- unlimited manual listing uploads by you
- SEO services
- running ads
- full social media work
- full branding work

Best line:

> Monthly support means the site stays handled, issues get fixed, and you do not need to deal with technical stuff yourself.

---

## 6. Sales Positioning

Never pitch the tech first.

Pitch outcomes:
- premium image
- more trust
- direct enquiry path
- WhatsApp-first conversion
- simpler follow-up
- easier content control

Good positioning lines:
- premium property dealer website
- direct WhatsApp lead system
- serious buyer and seller enquiry website
- Gurgaon-focused dealer website
- easy admin for listings and content

Bad positioning lines:
- custom React app
- admin-lite CMS
- Google Apps Script architecture
- structured content backend

## 9. Client Qualification SOP

Before investing time, ask:
- which city/market do you focus on
- buy, rent, sell, or all three
- do you already have a website
- do you want direct enquiries
- do you use WhatsApp for most leads
- do you have logo and photos ready
- who will manage listings/content

Red flags:
- wants too much for too little money
- no clarity at all
- keeps delaying advance
- wants unlimited changes
- says “bas sasta bana do”

---

## 10. Pricing SOP

Recommended pricing:
- `₹25,000` setup
- `₹1,000/month` support

Alternative options:
- `₹25,000` setup + first month free support
- `₹25,000` setup + `₹5,000/year` support

Best simple offer:

> 25,000 one-time setup and 1,000 per month support and maintenance.

---

## 11. Advance Payment SOP

Always take advance.

Recommended:
- `50%` upfront
- `50%` before final handover or launch

Never do full custom work before advance.

If the client delays payment too much:
- slow down
- do not continue unlimited work

## 14. Launch SOP

Recommended stack:
- Vercel hosting
- Google Sheets
- Google Apps Script
- custom domain if client wants one

### Launch Steps
1. final content ready
2. final logo/images ready
3. map ready
4. lead flow tested
5. admin tested
6. deploy to live
7. connect domain if needed
8. test live again
9. hand over links and password

## 15. Pre-Launch QA SOP

Before launch, always check:
- homepage
- buy page
- rent page
- sell page
- property detail page
- localities page
- locality detail page
- contact page
- Google map
- all WhatsApp buttons
- all call buttons
- lead forms
- admin login
- admin save for each section
- mobile responsiveness

Critical checks:
- lead saves to Google Sheet
- WhatsApp opens correctly
- no fake success state
- no broken links

---

## 16. Domain and Hosting SOP

Best practical model:
- hosting handled by you
- client does not need to think about it
- domain ideally in client’s own name/account

Why domain should preferably be in client ownership:
- less future drama
- client trust stays high
- they feel secure
- you still manage the technical setup

Best line:

> The site will stay handled from my side. You do not need to worry about hosting or technical setup.

---

## 17. Handover SOP

After launch, give the client:
- live website link
- admin link
- admin password
- simple instructions for admin
- support terms
- your contact for support

Explain only the essentials:
- how to log in
- how to change listings
- how to change contact details
- how to change images
- how leads arrive
- how WhatsApp is used

Do not overload the client with technical details.

---

## 18. Post-Launch SOP

After launching:
- send one test lead
- confirm it reaches Google Sheet
- confirm WhatsApp opens
- confirm admin changes save properly
- fix any urgent issue quickly

Then:
- ask for testimonial
- ask for referral
- ask if they know another dealer or business owner

---

## 19. Upsell SOP

- SEO
- Google Business Profile help
- domain setup help
- branded email help
- landing pages
- more city expansion
- content refresh

Do not dump all upsells at once.
Offer them later, after trust is built.

## 20. Objection Handling

### Objection: “Website se lead aayegi kya?”
Answer:

> Website ka main kaam hai trust build karna, WhatsApp pe enquiry lena, aur direct lead route banana. Portal pe depend kam hota hai aur premium image banti hai.

### Objection: “Mere paas already 99acres/Magicbricks hai.”
Answer:

> Portal pe sab same dikhte hain. Apni website se direct brand banta hai, client trust zyada hota hai, aur WhatsApp pe direct conversation aa sakti hai.

### Objection: “Itna kyu?”
Answer:

> Ye sirf basic brochure site nahi hai. Isme premium presentation, enquiry system, WhatsApp flow, lead capture, and admin control hai.

### Objection: “Monthly kyu?”
Answer:

> Monthly support ka purpose hai ki aapko hosting, technical issues, chhote updates, aur site running ki tension na leni pade.

## 22. Collaboration SOP

- use GitHub
- keep `main` branch stable
- use separate branches
- merge after testing
- do not expose `.env`
- keep only `.env.example` in repo

Coordinate who edits what.
